# 实验室管理台（小鼠 / 试剂 / 耗材）

单文件、离线、免安装。双击 `index.html` 用 Edge / Chrome 打开即可用，数据存在本机浏览器里。

## 一、功能

| 模块 | 内容 |
|---|---|
| **小鼠统计** | 品系、性别、周龄（填出生日期自动算，或手填周龄按记录日推算到今天）、**笼子数量**、**只数/笼**、自动算总只数、**实验目的**、项目、耳号/笼号、房间架位、负责人、在养/已结束状态 |
| 小鼠汇总 | 概览页按品系汇总：记录数 / 笼数 / 只数 / 周龄范围 / 实验目的 / 项目，底部合计 |
| 试剂 | 名称、货号、品牌、规格、类别、库存、单位、库存下限、存放位置、开封日期、有效期、供应商、备注 |
| 耗材 | 名称、规格、库存、单位、安全库存、存放位置、供应商 |
| 出入库 | 试剂/耗材每次入库、出库都留流水（日期、数量、操作人、备注），自动扣/加库存；出库超过库存会被拦住 |
| 提醒 | 试剂已过期 / N 天内到期 / 低于库存下限；耗材低于安全库存（阈值天数可改） |
| 打印 | 「🖨 打印笼牌」把当前筛选的笼子打成 A4 卡纸笼牌（品系、周龄、笼数、只数、实验目的、负责人、日期） |
| 导出 | 小鼠、试剂、耗材、流水各自导出 CSV（UTF-8 BOM，Excel/WPS 双击不乱码） |
| 备份 | 一键下载 JSON 全量备份；可从 JSON 恢复；可清空重来 |

计算规则：**总只数 = 笼子数量 × 只数/笼**。周龄按“今天”实时换算。

## 二、常用操作

1. **新增小鼠**：小鼠统计 → 「+ 新增记录」→ 填品系、笼子数量、只数/笼、实验目的（必填）→ 保存。弹窗底部实时显示 `合计 N 只`。
2. **批量录入**：同一品系不同笼号就是多条记录；同一条里只写同品系同目的的一批（笼数 × 只数/笼）。
3. **实验结束**：行尾点「结束」，记录保留但不再计入在养统计（可再点「恢复」）。
4. **试剂到货/消耗**：试剂页行尾「出入库」→ 选入库/出库 → 数量 → 填操作人 → 保存。
5. **找东西**：顶部搜索框支持名称、货号、位置、实验目的、项目、耳号等模糊搜索；下拉框按状态/品系/类别过滤。
6. **周龄自动更新**：填了出生日期，过一段时间再打开，周龄自己往上长。

## 三、数据安全（重要）

- 数据存在**当前浏览器**的 `localStorage`，键名 `labmgmt.v1`。
- 换电脑、换浏览器、清浏览器缓存、用无痕窗口 → **数据不会跟着走**。
- 所以：每周到「💾 数据备份」点一次 **下载 JSON 备份**，存到网盘/OneDrive。
- 换机器：把 `index.html` 和最新 JSON 一起拷过去，打开后「从 JSON 恢复」。
- 手机/平板也能打开，但与电脑**不互通**。
- 多人同时用：**不要**把同一个文件放共享盘各自打开（会变成互不同步的多份数据）。需要多人共用，可改成局域网小服务器版（SQLite 存一份，浏览器访问）。

## 四、文件位置

- 程序：`D:\lab-mgmt\index.html`
- 桌面快捷方式：`实验管理（小鼠·试剂·耗材）`
- 建议把本文件夹放进 OneDrive/BaiduSyncdisk 一起同步（注意：同步的是程序，数据在浏览器里，仍要手动导 JSON）。
